**PRODUCT REQUIREMENTS (Gmail Integration):**

*   **Objective**: Enable users to send, receive, track, and automate recruiting emails directly within the Volleyball Recruiting Board, with full two-way synchronization with their Gmail account.

*   **1. Gmail Account Integration**:
    *   Authenticate using Google OAuth 2.0.
    *   Allow connecting one or more Gmail accounts.
    *   Securely store and refresh access tokens.
    *   Allow users to disconnect Gmail at any time.

*   **2. Receiving Emails (Inbound)**:
    *   Read incoming emails from Gmail in near real-time.
    *   Support Gmail threads/conversations.
    *   Sync emails and associate them with a specific school, coach, and recruiting stage.
    *   Store email metadata (From/To/CC, Subject, Body, Attachments, Timestamps, Gmail IDs).
    *   Sync read/unread status.
    *   Emails sent directly from the user's Gmail must appear in the app.

*   **3. Sending Emails (Outbound)**:
    *   Compose and send emails from within the app using the connected Gmail account.
    *   Support Reply/Reply-All to preserve threads.
    *   Attach files and video links.
    *   Use email templates.
    *   Sent emails must appear in the user's Gmail Sent folder.

*   **4. Two-Way Synchronization**:
    *   Full bidirectional sync between the app and Gmail.
    *   Avoid duplicates and maintain correct threading.
    *   Sync status changes (e.g., labels) where applicable.

*   **5. Recruiting-Specific Automation**:
    *   Expose email events to internal automation agents.
    *   Detect coach replies to update recruiting status.
    *   Trigger reminders for no-replies.
    *   Suggest next actions based on email content (e.g., camp invites).

*   **6. User Interface**:
    *   Embedded email inbox within each recruiting record.
    *   Conversation-based (threaded) email view.
    *   Clear visual indicators for unread replies, last contact date, and follow-ups due.
    *   One-click reply functionality.

*   **7. Security & Compliance**:
    *   Use the Gmail API (not IMAP/SMTP).
    *   Request least-privilege scopes.
    *   Encrypt OAuth tokens at rest.
    *   Log all sent emails for auditing.

*   **8. Technical Expectations**:
    *   Use Gmail API with push notifications (watch).
    *   Design a scalable backend, database schema, and API contracts.
    *   Implement robust error handling and retries.
