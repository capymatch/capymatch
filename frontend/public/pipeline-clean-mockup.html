Key Design Decisions
1. Ring chart uses opacity ramp of one hue instead of 5 colors — same info, less noise
2. Division badges are all neutral — "D1" text already communicates the meaning
3. Stage names are text-only — grouped by section header, not painted with color
4. Only overdue gets red — urgency is preserved, everything else is calm
5. Left border accent on overdue rows replaces the colored stage pill
6. Match % is muted gray — it's context, not a competing signal
