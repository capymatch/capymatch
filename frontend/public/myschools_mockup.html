Design Notes

What This Replaces
  • A single dark card saying "No schools on your board yet"
  • One lonely "Find Schools" button
  • A vast, empty dark page below
What This Adds
  • Progress strip — shows where they are in the setup journey
  • Personalized hero — uses athlete's name, sets expectations
  • Three action paths — AI match, browse by division, search by location
  • AI-suggested schools — page is never truly empty
  • Ghost board preview — shows what the filled board looks like
  • Social proof strip — normalizes behavior we want
Key Principles

A new parent should never feel lost. The page should never feel empty. Every pixel should either motivate, educate, or move them forward.

Emotional Journey
  • Before: "This is empty. What do I do?" → feels like a dead end
  • After: "It already has suggestions for me!" → feels like a head start
Technical Notes
  • AI suggestions use existing /api/recruiting-profile/suggestions endpoint
  • Match scores come from the existing recommendation engine
  • "+ Add to Board" uses existing /api/programs POST
  • Ghost board is pure CSS, no data needed
