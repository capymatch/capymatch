Design Notes

What Changed
  • Replaced 4 generic stat cards with a personalized greeting + contextual pulse strip
  • Added "Today's Actions" as the hero section — overdue follow-ups and first-outreach targets
  • Added School Spotlight horizontal cards with smart next-step nudges
  • Simplified Pipeline Funnel to a clean vertical bar chart
  • Added a Recent Activity feed showing momentum across all schools
  • Redesigned Events to a compact date-box layout
What Was Removed
  • Donut chart (redundant with pipeline view)
  • Engagement Summary (duplicates stats already shown)
  • Fake trend arrows (+12%, +8%) — parents don't need these
  • Profile Views stat (low value for most users)
Key Principle

Every pixel on this dashboard should help a parent answer one of three questions: "What do I do today?", "How's it going?", or "What's coming up?" If it doesn't serve one of those, it's clutter.
